## Verification

- Frontend: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm licenses:check`, `pnpm build` on every PR. Tests grew from 97 to 112 across 22 files (help language, manual vocabulary, screen-module exports, grouped Undo, coach brief, section deletion, setlist grooves, replaced proposals, close guard, chord voicings).
- Rust: `cargo fmt --check`, `cargo clippy -D warnings`, `JAM_HEADLESS=1 cargo test --workspace`, `cargo deny check` on every engine PR; the app crate grew from 33 to 38 tests (warn-once, tolerant cache rows, headless guard, Windows shim rule, clip cache; the narrowed ACL is asserted).
- The opt-in FFmpeg mix test (`JAM_MEDIA_TEST=1`) was run against FFmpeg 9.0.1 to choose the limiter: 0.2 + 0.4 stays 0.6, eight loud inputs peak at 0.891, and the lookahead delays the file by three frames at 48 kHz.
- Chord shapes were checked visually in the browser preview at 1440 × 900 (Stage box with picker and barre bar, compact box in the Write inspector).
- CI (gitleaks, offline links, ts, rust on Windows and macOS) green on every PR before merge.
