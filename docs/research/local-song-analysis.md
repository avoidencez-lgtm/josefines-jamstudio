# Local reference analysis

The M3 fallback is implemented in `jam-dsp::offline` and runs on the existing
media worker after local FFmpeg decoding. It does not replace provider analysis
or claim real-song acceptance. All results are explicitly low confidence.

The implementation uses positive RMS differences at 20 ms intervals and normalized
onset autocorrelation over roughly 50–200 BPM. Adjacent onset intervals refine
the selected period; circular phase agreement rejects an incoherent pulse.
Half/double-tempo ambiguity and expressive timing remain limitations. Beat zero
does not claim to be a downbeat. No meter or named section is invented.

Stereo channel spectra contribute energy independently, avoiding cancellation
from opposite-polarity channels. A Hann-windowed 8192-point FFT at the center of
each estimated beat folds 60–2000 Hz bins into twelve pitch classes. Major/minor
triad template similarity yields an estimate only when all three tones have
support and the best match is sufficiently distinct. With no pulse, half-second
windows provide a time-based harmonic sketch. Key estimation correlates the
aggregate chroma with Krumhansl-Kessler profiles; sparse/ambiguous evidence is null.

Primary method references checked 2026-09-06:

- [FMP template chord recognition](https://www.audiolabs-erlangen.de/resources/MIR/FMP/C5/C5S2_ChordRec_Templates.html)
- [FMP autocorrelation tempo analysis](https://www.audiolabs-erlangen.de/resources/MIR/FMP/C6/C6S2_TempogramAutocorrelation.html)
- [Humdrum keycor and key profiles](https://extras.humdrum.org/man/keycor/)
- [RealFFT API and MIT license](https://docs.rs/realfft/3.5.0/realfft/)

RealFFT and SHA-256 reuse versions already in the dependency lock. No third-party
analysis implementation or audio asset was copied. The synthetic C–F–G fixture is
generated by the Rust test: 24 beats at 90 BPM, decaying triads, inverted stereo.
The same checks cover Am–Dm–E at 120 BPM and the corresponding minor key.
Its gate is at least 90% correct chord windows, tempo within 1 BPM and beats within
100 ms. Silence yields no pulse/key/chords; cancellation and invalid samples fail.
This is a synthetic algorithm gate, not the M3 player synchronization or real-mix
quality gate. Dense mixes, inversions and extended chords require stronger analysis.

The opt-in FFmpeg integration check verifies decode, persistence, source integrity,
unknown-field preservation, reload and cancellation against actual local files.
Network providers, stems, cloud fixtures and subjective audio quality are separate.
